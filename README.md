# جاویدنامان استان مرکزی

سایت استاتیک و قابل انتشار با GitHub Pages.

## ویرایش اطلاعات
اطلاعات افراد در `data/people.json` است. هر رکورد شامل نام، سن، محل، تاریخ، توضیح، منابع و مسیر عکس است.
عکس‌ها در پوشه `images/` هستند.

## انتشار با GitHub Pages
فایل‌ها را در ریشه یک repository عمومی قرار دهید و در Settings > Pages، شاخه main را برای انتشار انتخاب کنید.

نکته: موارد «نامشخص» یا «نیازمند تأیید» عمداً حدس زده نشده‌اند.
